# 📐 Resize & HD Upscale

Resize images using custom dimensions or predefined presets.

### Available Presets

```text
Custom
2× HD
3× HD
4× HD

1920 × 1080
2560 × 1440
3840 × 2160
```

Features:

<ul>
<li>Custom width</li>
<li>Custom height</li>
<li>Aspect ratio lock</li>
<li>High-quality Lanczos resizing</li>
<li>Sharpening enhancement</li>
<li>HD / 4K presets</li>
</ul>

<blockquote>
<strong>Note:</strong> The current upscaling system uses high-quality Lanczos resampling and sharpening. It is not a neural-network AI upscaler.
</blockquote>

# ⚡ Fast Background Processing

Image conversion runs using a background worker so the application remains responsive while processing images.

The live log provides information such as:

```text

Format: JPEG • Files: 10

Converting: image01.heic
✓ Saved: image01_converted.jpg

Converting: image02.heic
✓ Saved: image02_converted.jpg

✓ Finished • Success: 10 • Failed: 0
```

# 🚀 Installation

## 1️⃣ Clone The Repository

```bash
git clone https://github.com/YashvirGaming/yashvir-gaming-image-studio.git
```

```bash
cd yashvir-gaming-image-studio
```

## 2️⃣ Install Dependencies

```bash
python -m pip install PySide6 Pillow pillow-heif
```

## 3️⃣ Launch

```bash
python yashvir_image_studio.py
```

# 📖 Usage

## Convert HEIC → JPG

```text
1. Open Yashvir Gaming Image Studio
2. Open Converter
3. Drag & Drop your HEIC image
4. Select JPEG
5. Select quality
6. Click Convert
7. Click Open Results
```

## Bulk Conversion

```text
1. Add Images OR Add Folder
2. Select multiple images
3. Choose output format
4. Click Convert
5. Monitor the live log
6. Open Results
```

## Edit Images

```text
Editor
  ↓
Open Image
  ↓
Adjust Brightness / Contrast / Saturation
  ↓
Apply Effects
  ↓
Save As
```

## Resize / Upscale

```text
Resize & HD Upscale
        ↓
Select Image
        ↓
Choose Resolution
        ↓
Adjust Sharpening
        ↓
Resize / Upscale
        ↓
Save Result
```

# 🔐 Privacy

<strong>Local Processing</strong>

Your images are processed locally on your computer.

The application does not require an online account or cloud upload for normal image processing.

Your photos stay on your machine unless you choose to share them yourself.
